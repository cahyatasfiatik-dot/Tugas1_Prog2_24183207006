# Tugas1_Prog2_24183207006
Class Mahasiswa Sebagai cetakan (blueprint) untuk membuat objek mahasiswa.
Atribut:
nama → menyimpan nama mahasiswa
npm → menyimpan Nomor Pokok Mahasiswa
jurusan → menyimpan jurusan/program studi
Metode:
nama(String NamaMahasiswa) → mengisi data nama
npm(String NpmMahasiswa) → mengisi data npm
jurusan(String JurusanMahasiswa) → mengisi data jurusan
tampil() → menampilkan data mahasiswa ke layar

Class NewClass Berisi method main sebagai titik awal eksekusi program.
Isi utama:
Membuat objek Mahasiswa (contoh: mhs1, mhs2).
Mengisi atribut nama, npm, dan jurusan menggunakan metode dari class Mahasiswa.
Menampilkan data tiap mahasiswa dengan memanggil tampil()
